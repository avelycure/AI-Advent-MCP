# Day 20: catalog MCP server

Первый сервер учебной оркестрации. Он не обращается во внешнюю сеть и отдаёт
детерминированный каталог через два инструмента:

- `search_learning_resources` — найти компактный список по теме;
- `get_resource_details` — раскрыть длительность и модули выбранного ресурса.

Запуск:

```bash
npm install
npm run server
```

По умолчанию сервер слушает `http://127.0.0.1:3102/mcp`. Порт задаётся через
`MCP_CATALOG_PORT`.

Полный запуск оркестратора и наглядный trace описаны в `../mcp3/README.md`.
